# Python Odyssey 

A collection of beginner-to-intermediate Python projects built during a personal 7-day coding challenge.

The main purpose of this challenge was not only to practice Python fundamentals, but also to improve problem-solving skills and gain hands-on experience using Git and GitHub in a real workflow.

##  Goals

- Practice Python concepts through small practical projects
- Improve code organization and problem-solving
- Learn how to use Git and GitHub consistently
- Build the habit of developing projects incrementally

---

## 📚 Completed Projects

### 1. Smart Character Counter
A character counting program that tracks how many times a specific character appears in a text without using `.count()`.

**Features & Concepts**
- for loops
- string iteration
- conditions
- file handling
- reusable functions

---

### 2. Simple ATM Simulator
A terminal-based ATM simulator that supports deposits and withdrawals with balance validation.

**Features & Concepts**
- functions
- conditions
- input validation
- balance management
- modular logic

---

### 3. Password Validator
Validates passwords based on custom rules such as length and required symbols.

**Features & Concepts**
- validation systems
- string operations
- conditional logic
- reusable checks

---

### 4. Guessing Game
A number guessing game with limited attempts and higher/lower hints.

**Features & Concepts**
- loops
- comparisons
- game logic
- attempt tracking

---

### 5. Duplicate Remover
Transfers unique values from one list to another without duplicates.

**Features & Concepts**
- lists
- loops
- manual duplicate filtering

---

### 6. Sentence Reverser
Reverses the order of words in a sentence using list operations.

**Features & Concepts**
- split()
- join()
- list manipulation

---

### 7. Billing Calculator
Calculates the final bill with tax after continuously receiving product prices.

**Features & Concepts**
- while loops
- exception handling
- numeric operations
- user input validation

---
