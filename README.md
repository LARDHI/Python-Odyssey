# Python-Odyssey

A collection of beginner Python challenges completed during a personal 7-day coding challenge.

## 🎯 Goal

Improve Python fundamentals and problem-solving skills through practical mini-projects.

## 📚 Completed Challenges

### 1. Smart Character Counter
Counts character occurrences without using `.count()`.

**Concepts practiced:**
- for loops
- string iteration
- conditions

---

### 2. Simple ATM Simulator
Supports deposits and withdrawals with balance validation.

**Concepts practiced:**
- functions
- conditions
- user input

---

### 3. Password Validator
Validates password length and required symbols.

---

### 4. Guessing Game
3-attempt number guessing game with hints.

---

### 5. Duplicate Remover
Removes duplicate values manually from a list.

---

### 6. Sentence Reverser
Reverses sentence word order using lists and `split()`.

---

### 7. Billing Calculator
Calculates final bill with 15% tax.

## 🛠 Skills Practiced

- Variables
- Loops
- Functions
- Lists
- String Manipulation
- Exception Handling

## 📈 What I Learned

- Breaking problems into smaller steps
- Organizing code with functions
- Handling invalid input
- Improving program structure
